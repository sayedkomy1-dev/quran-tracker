# أكاديمية الإمام لتحفيظ القرآن الكريم — بالقرآن نحيا

إصدار **7.0.0** من نظام أكاديمية الإمام لتحفيظ القرآن الكريم.

التطبيق **PWA Local‑First**: لا يحتاج Build ولا Backend للتشغيل الأساسي، ويعمل بعد أول تحميل بدون إنترنت. الإصدار 7 صُمم ليعطي تجربة أقرب لتطبيق أصلي على **Android** و**Windows** مع الاحتفاظ ببيانات الطلاب محلياً على الجهاز.

## ما الجديد في v7.0

- واجهة متجاوبة جديدة حسب الجهاز:
  - **Android / الهاتف:** شريط تنقل سفلي، مساحات لمس أكبر، Bottom Sheets، دعم Safe Area وحواف الشاشات الحديثة.
  - **Windows / الكمبيوتر:** Sidebar ثابت، مساحة عمل أعرض، نافذة PWA مستقلة، ودعم `window-controls-overlay` في المتصفحات التي تدعمه.
- **مركز اليوم الذكي** في الرئيسية يعرض الحصة التالية، حالة اليوم، والمهام المفتوحة.
- **نظام مهام ومتابعة كامل**: مهمة عامة أو لطالب محدد، موعد استحقاق، أولوية، مكتملة/مفتوحة، ومتأخرة/اليوم.
- **تنبيهات متابعة ذكية محلية** لاكتشاف الطلاب الذين طال غيابهم عن المتابعة، ضعف متوسط التسميع، تكرار الغياب، أو وجود مهام مفتوحة.
- **المجموعات / الحلقات** لكل طالب، مع بحث وفلترة وعرض المجموعة في ملف الطالب وقائمة الطلاب.
- **بحث سريع شامل** عن الطلاب والمهام والشاشات عبر زر البحث أو `Ctrl/⌘ + K`.
- اختصارات لوحة مفاتيح للكمبيوتر:
  - `Alt + 1…6` للتنقل بين الصفحات الأساسية.
  - `Ctrl/⌘ + K` للبحث السريع.
  - `Ctrl/⌘ + N` لإضافة طالب.
  - `Ctrl/⌘ + Enter` لحفظ الحصة الحالية.
  - `Esc` لإغلاق النوافذ أو الرجوع.
- **مركز حالة الجهاز** في الإعدادات: نوع النظام، هل التطبيق مثبت، حالة الاتصال، استهلاك التخزين، وحالة حماية التخزين.
- طلب **Persistent Storage** عندما يدعمه المتصفح لتقليل احتمال تنظيف البيانات المحلية تلقائياً.
- **مشاركة النسخة الاحتياطية** مباشرة عبر Share Sheet على Android أو تنزيلها تلقائياً على الأنظمة التي لا تدعم مشاركة الملفات.
- تحسين Service Worker والتحديثات والعمل Offline، مع Navigation Preload وتنظيف الكاش القديم.
- دعم أفضل لتفضيل `prefers-reduced-motion` وتحسينات أداء عند القوائم الطويلة.
- Schema Version أصبح **8** مع دعم ترقية بيانات v6/v6.2 تلقائياً.

## الوظائف الأساسية الموجودة أيضاً

- إدارة الطلاب وبيانات أولياء الأمور.
- جدول أسبوعي لكل طالب مع اكتشاف تعارضات المواعيد.
- تسجيل الحضور: حضر / غاب / إجازة.
- سجل واحد للطالب في اليوم لمنع ازدواج الحضور والحصة.
- إدارة الحفظ الجديد والمراجعة القريبة والبعيدة والأجزاء والسور.
- تسجيل **ما تم تسميعه فعلياً** وليس التكليف فقط.
- Autosave لمسودة الحصة واستعادتها.
- حساب الآيات الفريدة بدون تضخيم النتيجة عند تداخل النطاقات.
- تقارير شهرية، تقويم، رسوم Canvas، CSV وطباعة PDF.
- رسائل واتساب فردية وجماعية بقوالب ومتغيرات.
- شهادة تقدير قابلة للطباعة.
- نسخ احتياطي JSON بإصدار Schema مع Sanitization وفحص قبل الاستيراد.
- Dark Mode وأحجام خط متعددة.

## التثبيت على Android

1. ارفع المشروع على HTTPS، مثل GitHub Pages أو الدومين الحالي.
2. افتح الموقع في Chrome على Android.
3. استخدم زر **تثبيت التطبيق** داخل الإعدادات، أو من قائمة Chrome اختر **تثبيت التطبيق / Add to Home screen**.
4. بعد التثبيت سيعمل التطبيق في نافذة مستقلة ويعمل Offline بعد أول تحميل كامل.
5. من **الإعدادات → الجهاز والتثبيت** اضغط **حماية التخزين المحلي** إذا كان المتصفح يدعمها.

> البيانات محلية على نفس متصفح/تطبيق الجهاز. خذ Backup قبل حذف بيانات Chrome أو تغيير الهاتف.

## التثبيت على Windows

1. افتح الموقع في Microsoft Edge أو Google Chrome عبر HTTPS.
2. من شريط العنوان اضغط Install App، أو استخدم زر **تثبيت التطبيق** داخل الإعدادات.
3. ثبّت التطبيق ليظهر كتطبيق مستقل في Start Menu ويمكن تثبيته في Taskbar.
4. استخدم اختصارات لوحة المفاتيح المذكورة أعلاه لتسريع العمل اليومي.

## التشغيل محلياً

لا توجد خطوة Build:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

لا تفتح `index.html` بصيغة `file://` للاستخدام الفعلي لأن Service Worker وميزات PWA تحتاج HTTP/HTTPS.

## الاختبارات

يوجد فحص Static بدون Dependencies:

```bash
npm test
```

ويتحقق من:

- Syntax لـ `app.js` و`sw.js`.
- تطابق رقم الإصدار بين الملفات.
- صحة `manifest.json`.
- وجود عناصر v7 الأساسية والأيقونات.

## النشر على GitHub Pages

المشروع جاهز من جذر المستودع. ملف `CNAME` الحالي:

```text
welivequran.online
```

الخطوات المختصرة:

1. ارفع الملفات الموجودة في هذا المجلد إلى جذر فرع `main`.
2. من GitHub: **Settings → Pages → Deploy from a branch**.
3. اختر `main` و`/(root)`.
4. تأكد من الدومين المخصص وفعّل **Enforce HTTPS**.
5. بعد رفع v7 سيكتشف Service Worker الإصدار الجديد ويظهر Banner للتحديث داخل التطبيق.

راجع [DEPLOYMENT.md](DEPLOYMENT.md) للتفاصيل.

## البيانات والخصوصية

- الطلاب والحصص والمهام والإعدادات مخزنة في IndexedDB، مع نسخة أمان في localStorage.
- لا يرسل التطبيق قاعدة بيانات الطلاب إلى خادم خارجي.
- واتساب يُفتح فقط بعد إجراء المستخدم.
- النسخ الاحتياطي الدوري مهم جداً، خصوصاً قبل تغيير جهاز أو مسح بيانات المتصفح.
- المزامنة Cloud Sync بين جهازين **غير مفعلة** في v7؛ كل جهاز له قاعدة بيانات محلية مستقلة ما لم تنقل Backup يدوياً.

## الانتقال من v6 / v6.2

عند نشر v7 على **نفس الدومين** وفتحه من **نفس المتصفح/الجهاز**، يقرأ التطبيق قاعدة `QuranApp` الحالية ويجري Migration إلى Schema 8. بيانات الطلاب والحصص السابقة تظل كما هي، وتُضاف الحقول الجديدة مثل `group` وقائمة `tasks` بقيم افتراضية آمنة.

يفضل أخذ Backup من النسخة القديمة قبل أول تشغيل للإصدار الجديد.

## حدود الإصدار الحالي

- لا توجد حسابات مستخدمين أو صلاحيات متعددة.
- لا يوجد Cloud Sync أو مزامنة تلقائية بين Android وWindows.
- الإشعارات الخلفية الحقيقية أثناء إغلاق التطبيق تحتاج Push Backend؛ الموجود حالياً هو تذكير محلي عند تشغيل/استخدام التطبيق.
- PWA هي طريقة التثبيت الأساسية؛ لا يوجد APK أو EXE منفصل داخل هذا المستودع.
