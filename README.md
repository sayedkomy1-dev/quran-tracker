# أكاديمية الإمام — v10.1 Clean PWA

إعادة بناء نظيفة للمشروع كـ **Web App / PWA** بدون Python وبدون طبقات `v8.js` و`v9.js` المتراكمة.

## فلسفة الإصدار

- الصفحة الرئيسية تبقى بسيطة: أرقام اليوم + بدء الحصة + طلاب اليوم + 4 اختصارات فقط.
- شاشة الحصة هي مركز العمل اليومي، ولا توجد أزرار حفظ عائمة فوق المحتوى.
- IndexedDB هو المخزن الرئيسي، مع محاولة استيراد بيانات الإصدار القديم تلقائيًا من `qt_st` و`qt_ses` عند أول تشغيل.
- يعمل كتطبيق قابل للتثبيت على Android وWindows عبر PWA.
- لا يوجد Backend إجباري.

## ما نُفذ في هذه المرحلة

- Home جديدة مبسطة.
- إدارة الطلاب: نشط / متوقف / مؤرشف، مفضلة، مجموعة، موعد وخطة.
- حضور سريع و«حضر الجميع».
- شاشة حصة نظيفة مع حفظ/إرسال في **نهاية الصفحة فقط**.
- التقييم داخل التسميع فقط.
- زر «النص» داخل تسميع الحفظ الجديد والمراجعة القريبة والبعيدة، وكذلك بجوار الحفظ الجديد القادم.
- سجل أخطاء التسميع و«اقتراح المراجعة» كأقسام قابلة للفتح والإغلاق ومغلقة افتراضيًا.
- زر «نفس التكليف للحصة القادمة» يظهر عند التقييم «ضعيف».
- مراجعة الأجزاء ومراجعة السور مستقلة.
- مراجعة الأجزاء/السور تعمل على مستوى كل سورة: `تم / يعاد / لم يُسمع`، ويمكن نقل المتبقي فقط للحصة القادمة.
- أسماء الأجزاء بدل الأرقام المجردة.
- اتجاه مستقل لكل مسار.
- نص قرآني عثماني عند الطلب مع الحصري ومشاري، السرعة، التكرار ووضع التلقين.
- مصحف المدينة: تنزيل PDF مع نسبة تقدم + إيقاف مؤقت/متابعة/إلغاء + fallback للرابط الخارجي والاستيراد + تخزينه في IndexedDB للعمل Offline.
- رسالة واتساب تفصيلية أو مختصرة، مع اسم الأكاديمية و«بالقرآن نحيا» ورابط Facebook من الإعدادات.
- 4 لوحات ألوان، والافتراضية Emerald & Ivory.
- Manifest كامل مع أيقونة `maskable` ليظهر شعار التطبيق على الهاتف بعد التثبيت.
- Backup/Restore JSON.
- قسم الحديث والدعاء: تحميل 200 حديث قصير منتقى من صحيح البخاري و60 دعاء/ذكر من حصن المسلم للعمل Offline بعد أول تنزيل.
- عرض الحديث مع النص، الراوي المستخرج من بيانات/سند المصدر، التخريج، الدرجة والتصنيف الموضوعي.
- ربط الحديث أو الدعاء بالطالب كمهمة أو تكليف أسبوعي.
- في الحصة التالية يمكن تحديد «حفظه» أو «يعاد» للحديث والدعاء السابق؛ وعند «يعاد» ينتقل تلقائيًا للتكليف القادم.
- يظل مطلوبًا إجراء مراجعة شرعية بشرية نهائية على القائمة المنتقاة قبل الطباعة أو النشر العام، لأن الانتقاء من المصدر يتم آليًا حسب القِصر.

## تشغيل محلي

يجب فتحه عبر HTTP وليس بالنقر المباشر على `index.html` لأن التطبيق يستخدم ES Modules وService Worker.

مثال باستخدام Node.js:

```bash
npx serve .
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

## GitHub Pages

ارفع **محتويات المجلد نفسه** إلى جذر المستودع، ثم:

`Settings → Pages → Deploy from a branch → main → /(root)`

## المصحف

الرابط الافتراضي داخل الإعدادات:

`https://pdf.quran.ws/pdfs/hafs/quran-hafs-mushaf.pdf`

الملف 604 صفحات وحجمه كبير (نحو 210MB). إذا منع الخادم CORS فالتطبيق يفتح الرابط خارجيًا ثم يمكن استخدام «استيراد PDF» لتثبيته محليًا.
