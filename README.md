# أكاديمية الإمام لتحفيظ القرآن الكريم — بالقرآن نحيا

الإصدار **8.0.0** من نظام أكاديمية الإمام. التطبيق PWA عربي **Local‑First** يعمل من نفس المشروع على Android وWindows، ولا يحتاج Build أو Backend للتشغيل الأساسي.

> **تنبيه مهم قبل الترقية:** خذ نسخة احتياطية JSON من الإصدار المستخدم فعلياً قبل رفع v8. عند فتح v8 على نفس الدومين والمتصفح تتم ترقية البيانات تلقائياً إلى Schema 10.

## ما الجديد في v8.0

### 1) وضع الحصة السريع

شاشة الحصة أصبحت Teaching Cockpit واحداً، مع شريط انتقال ثابت بين:

- تسميع الحصة السابقة.
- سجل الأخطاء.
- الحفظ الجديد.
- المراجعة القريبة.
- المراجعة البعيدة.
- مراجعة الأجزاء.
- مراجعة السور.
- الملاحظات.

لا يحتاج المحفّظ للتنقل بين صفحات منفصلة أثناء الحصة.

### 2) فصل «ما تم تسميعه» عن «التكليف القادم»

يظهر لكل مسار:

- آخر ما تم تسميعه فعلياً.
- التكليف القادم المسجل.

كما أضيف للطالب خياران للاستكمال بعد التسميع:

- البدء من **آخر آية تم تسميعها** للربط.
- البدء من **الآية التالية**.

### 3) اتجاه مستقل لكل مسار

الاتجاه ↑/↓ مستقل لـ:

- الحفظ الجديد.
- المراجعة القريبة.
- المراجعة البعيدة.
- مراجعة الأجزاء.
- مراجعة السور.

مثال: عند إتمام سورة **المجادلة** يمكن اختيار ↑ للانتقال إلى **الحديد** أو ↓ للانتقال إلى **الحشر**.

### 4) مراجعة ذكية متباعدة

يبني التطبيق موعد المراجعة المقترح من سجل تقييمات الطالب:

- ممتاز: يباعد المراجعة تدريجياً.
- جيد جداً: فاصل متوسط.
- جيد: مراجعة أقرب.
- ضعيف: مراجعة سريعة.

الاقتراح قابل للتعديل دائماً ولا يجبر المحفّظ على مسار معين.

### 5) سجل أخطاء التسميع

داخل الحصة يمكن تسجيل الخطأ بضغطة واحدة:

- حفظ.
- تردد.
- تلقين.
- تجويد.
- تشكيل.
- نسيان آية.

ويظهر في ملف الطالب تجميع لأكثر الأخطاء تكراراً.

### 6) خريطة تقدم المصحف

ملف الطالب يعرض السور كخريطة حالات، بدون نسب مئوية:

- محفوظ.
- جارٍ الحفظ.
- يحتاج مراجعة.
- لم يبدأ.

ويظهر أيضاً سجل الأجزاء التي دخلت في المراجعة.

### 7) Timeline للطالب

سجل زمني للحضور والتسميع والتقييم والتكليف والملاحظات والملاحظات الصوتية.

### 8) «أين توقفنا؟»

بطاقة مختصرة في شاشة الحصة وملف الطالب تعرض نقطة التوقف في الحفظ والمراجعات والأجزاء والسور.

### 9) تكرار نفس التكليف

زر مستقل لكل مسار لإعادة نفس التكليف دون إعادة إدخال البيانات.

### 10) «تمت السورة»

زر يحدد السورة كاملة، والاستكمال الذكي ينتقل إلى السورة المجاورة بحسب اتجاه المسار.

### 11) خطط الطلاب

الخطط الجاهزة:

- متوازنة.
- مبتدئ.
- حفظ مكثف.
- مراجعة فقط.
- ختمة تثبيت.
- قصار السور.

الخطة تضبط الأقسام الافتراضية للحصة الجديدة، وكل شيء يبقى قابلاً للتعديل.

### 12) أهداف أسبوعية بدل النسب

الرئيسية تعرض أرقاماً مباشرة:

- آيات حفظ جديد.
- عدد المراجعات.
- عدد الحصص.
- عدد الحضور.

### 13) Dashboard مبسطة

أعلى الرئيسية:

- إجمالي الطلاب.
- حصص اليوم.
- حصص الشهر.
- غياب اليوم.
- حضور وغياب آخر 7 أيام.
- متوسط مستوى التسميع لفظياً.
- عدد آيات الحفظ الجديد هذا الشهر.

### 14) بحث السور والآيات

- البحث داخل قائمة السور بالاسم أو الرقم.
- تطبيع بسيط للهمزات والتشكيل أثناء البحث.
- التحقق من الحد الأقصى لآيات كل سورة.
- منع نطاق خارج عدد آيات السورة.

### 15) ربط السور بعدد آياتها

يعرف التطبيق نهاية كل سورة ويستطيع الانتقال تلقائياً إلى السورة السابقة/التالية عند إتمامها.

### 16) شريط مختصر للحصة السابقة

يعرض «آخر تسميع» و«القادم» لكل مسار في أعلى الحصة.

### 17) ملاحظات صوتية

يمكن تسجيل ملاحظة صوتية حتى 30 ثانية داخل الحصة. تُخزن في IndexedDB على الجهاز، ويمكن تشغيلها من Timeline الطالب.

> الملاحظات الصوتية **محلية على الجهاز** في v8.0 ولا تُرفع في النسخة السحابية التجريبية ولا في Backup JSON التقليدي.

### 18) قوالب ملاحظات سريعة

عبارات متكررة تضاف بضغطة واحدة، مع إمكانية تعديل النص بعدها.

### 19) واتساب مختصر أو تفصيلي

يمكن إرسال:

- رسالة متابعة مختصرة.
- رسالة متابعة تفصيلية تشمل التسميع، التقييم، الأخطاء، التكليف القادم، والملاحظات.

كل رسالة تحمل هوية الأكاديمية وشعار **بالقرآن نحيا**.

### 20) تقرير شهري PDF

زر **تقرير PDF** في صفحة التقارير يفتح طباعة تقرير شهري منظم؛ اختر **Save as PDF / حفظ كملف PDF** من نافذة الطباعة.

### 21) قفل التطبيق

- PIN محلي من 4–8 أرقام.
- دعم WebAuthn للبصمة / Windows Hello على الأجهزة والمتصفحات الداعمة عبر HTTPS.
- إعادة القفل بعد الرجوع للتطبيق بعد غياب طويل.

> القفل طبقة خصوصية محلية للواجهة، وليس تشفيراً كاملاً لقاعدة IndexedDB.

### 22) نسخ احتياطية تلقائية

يحفظ التطبيق آخر **5 نسخ تلقائية** محلياً ويتيح استعادة واحدة منها من الإعدادات. يتم تجنب إنشاء نسخة جديدة على كل نقرة؛ النسخ تُباعد زمنياً.

### 23) مزامنة Android وWindows — اختيارية

أضيفت مزامنة تجريبية مشفرة عبر Supabase:

- البيانات تُشفّر في المتصفح بـ **AES‑GCM**.
- اشتقاق المفتاح من كلمة مرور المزامنة عبر PBKDF2/SHA‑256.
- لا تُرسل كلمة مرور التشفير أو PIN إلى السحابة.
- الدمج يعتمد على IDs و`updatedAt`.
- يمكن تشغيل المزامنة يدوياً أو تلقائياً.

ملف إعداد الجدول موجود في:

```text
sql/supabase-sync.sql
```

استخدم Sync ID صعب التخمين وكلمة تشفير قوية وفريدة. إعداد Supabase اختياري؛ التطبيق يعمل محلياً بالكامل بدونه.

## قارئ «النص» للحفظ الجديد

بجوار **الحفظ الجديد** يوجد زر **📖 النص**. بعد تحديد السورة ومن/إلى:

- يفتح النص المحدد فقط.
- العرض يستخدم **QPC Hafs Unicode / الرسم العثماني** مع خط Uthmanic Hafs من CDN الخاص بـ Quran Foundation.
- التطبيق يطلب نص `qpc_hafs`، مع fallback للرسم العثماني عند تعذر المصدر الأول.
- يتم تخزين السورة النصية في IndexedDB بعد أول تحميل لتقليل الطلبات.

القارئان المتاحان فقط كما هو مطلوب:

1. الشيخ **محمود خليل الحصري**.
2. الشيخ **مشاري راشد العفاسي**.

الصوت يعمل آية آية من نطاق الحفظ المحدد.

> النص والصوت يحتاجان اتصالاً بالإنترنت أول مرة. الخط القرآني يُحمّل من مصدره الرسمي بدلاً من تضمين ملف خط محلي داخل المشروع.

## مراجعة الأجزاء والسور

القسمان مستقلان تماماً. الأجزاء تظهر بالأسماء، ومنها:

- جزء قد سمع.
- جزء تبارك.
- جزء عمّ.

ولا يُستخدم «الجزء 28/29/30» كاسم العرض.

## التخزين والخصوصية

التشغيل الأساسي Local‑First:

- IndexedDB هو المخزن الرئيسي.
- localStorage نسخة أمان سريعة للبيانات الأساسية.
- آخر 5 Backups تلقائية محفوظة محلياً.
- لا توجد حسابات مستخدمين أو خدمة مركزية مطلوبة للتشغيل الأساسي.
- واتساب لا يفتح إلا بإجراء من المستخدم.
- المزامنة السحابية لا تعمل إلا إذا أدخل المستخدم إعدادات Supabase وفعّلها.

## التثبيت على Android

1. ارفع الملفات عبر HTTPS.
2. افتح الموقع في Chrome.
3. اختر **تثبيت التطبيق** / Add to Home Screen.
4. من الإعدادات اطلب حماية التخزين المحلي إن كانت مدعومة.
5. جرّب Backup قبل حذف بيانات Chrome أو تغيير الهاتف.

## التثبيت على Windows

1. افتح الموقع في Edge أو Chrome عبر HTTPS.
2. اختر Install App.
3. يمكن تثبيته في Start/Taskbar.
4. الاختصارات القديمة ما زالت تعمل، ومنها `Ctrl/⌘ + K` للبحث و`Ctrl/⌘ + Enter` لحفظ الحصة.

## التشغيل محلياً

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

لا تعتمد على `file://` لأن Service Worker وميزات PWA تحتاج HTTP/HTTPS.

## حدود v8.0

- الملاحظات الصوتية محلية على الجهاز ولا تنتقل بعد عبر Cloud Sync.
- المزامنة التجريبية تحتاج Supabase يديره صاحب المشروع؛ لا توجد خدمة سحابية مرفقة مسبقاً.
- النص القرآني والصوت يعتمدان على مصادر خارجية وقت الاتصال؛ عند انقطاع الشبكة يمكن عرض السور التي سبق تخزين نصها مؤقتاً، لكن تشغيل الصوت ليس مضموناً Offline.
- لا توجد صلاحيات متعددة للمعلمين/المديرين حتى الآن.
- PWA هي صيغة التثبيت؛ لا يوجد APK أو EXE منفصل في هذا المستودع.
