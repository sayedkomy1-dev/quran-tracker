> **ملاحظة v9.2:** تم تبسيط الصفحة الرئيسية وإعادة تصميم مسار تنزيل/تثبيت المصحف.

# أكاديمية الإمام لتحفيظ القرآن الكريم — بالقرآن نحيا

الإصدار **9.1.0** هو إصدار تثبيت وإصلاح شامل لطبقة **UX/UI v9** فوق كل وظائف v8، مع الحفاظ على نموذج Local‑First ودعم Android وWindows من نفس مشروع الـPWA.

**هدف 9.1.0 هو الاستقرار أولًا:** لم نحذف وظائف v8/v9؛ أصلحنا التداخل الذي أخفى إجراءات مهمة، وأعدنا «حفظ الحصة» و«حفظ وإرسال لولي الأمر» كإجراءات دائمة وواضحة على الهاتف وWindows.

> **قبل الترقية:** افتح النسخة المستخدمة فعليًا وصدّر Backup JSON. عند فتح v9 على نفس الدومين والمتصفح تتم ترقية البيانات إلى **Schema 11** مع الحفاظ على بيانات الطلاب والحصص والإعدادات المتوافقة.

## إصلاحات الاستقرار في v9.2.0

- إعادة زر **حفظ الحصة** وزر **حفظ وإرسال لولي الأمر** إلى شريط الإجراءات الثابت وعدم إخفائهما في الوضع المبسط أو السريع.
- إبقاء **رسالة مختصرة / رسالة تفصيلية** متاحتين من «خيارات رسالة ولي الأمر».
- ترقية مستخدمي v8 والنسخة الأولى من v9 تلقائيًا إلى **الوضع السريع** مرة واحدة حتى لا تبدو الأقسام القديمة وكأنها اختفت.
- إزالة Overrides خطرة كانت تعيد تعريف `save()` و`migrateV8Data()` داخل طبقة v9.
- إضافة Fail‑Soft: إذا تعطلت طبقة v9 لأي سبب، يبقى التنقل والوظائف الأساسية القديمة متاحة بدل شاشة ناقصة.
- Service Worker جديد باسم Cache مستقل `quran-pwa-v9.2.0` مع تفعيل سريع للتحديث حتى لا تظل النسخة المعطوبة عالقة في الكاش.
- إضافة Regression Tests للأزرار الحرجة، التنقل، الـhandlers، الملفات المحلية والتوافق بين v8/v9.

## وظائف v9 الأساسية

### واجهة احترافية موحدة

- Design System جديد بالأخضر والذهبي الخاصين بالأكاديمية، مع مسافات وأحجام لمس وتباين موحّدة.
- Bottom Navigation على Android وSidebar مخصص على Windows.
- تقليل الاعتماد على Emoji داخل الواجهة واستخدام SVG Icons موحّدة.
- دعم Focus واضح للكيبورد و`prefers-reduced-motion` وخيار تقليل الحركة من الإعدادات.
- حالات فارغة محسّنة، Toasts موحّدة، ومكوّنات Skeleton جاهزة للتحميل غير المتزامن.

### الرئيسية — Command Center

بدل كثرة البطاقات، تعرض الرئيسية ما يحتاجه المحفّظ فورًا:

- طلاب اليوم.
- تم / متبقٍ / غياب.
- زر كبير **ابدأ الحصة**.
- آخر الطلاب والمثبتون.
- ملخص آخر 7 أيام: آيات الحفظ، المراجعات، ومتوسط التسميع.
- Insight قصير مبني على سجل الأداء والأخطاء.
- اختصارات للحضور والطلاب والمصحف والحلقات.

### الطلاب والإدارة

- حالات الطالب: **نشط / متوقف مؤقتًا / مؤرشف**.
- تثبيت الطلاب المهمين أعلى القائمة.
- تحديد متعدد: نقل إلى مجموعة، إيقاف، أرشفة، ورسالة جماعية.
- قائمة سياقية بكليك يمين على Windows.
- Empty State واضح عند عدم وجود طلاب.
- Onboarding لأول تشغيل + Demo Mode اختياري.

### الحصة الموجّهة

شاشة الحصة أصبحت Workflow من أربع مراحل:

1. التسميع.
2. الحفظ الجديد.
3. المراجعة.
4. الملاحظات.

يوجد وضعان:

- **مبسّط**: يعرض خطوة واحدة في كل مرة.
- **سريع**: يعرض جميع الأقسام للمستخدم الخبير.

مع شريط إجراءات ثابت، أزرار زيادة/نقصان للآيات، وحفظ تلقائي لمسودة الحصة.

### ملف الطالب

تم تنظيم ملف الطالب إلى ثلاثة تبويبات رئيسية:

- **الخطة**: أين توقفنا وخريطة التقدم.
- **السجل**: Timeline الحصص.
- **التحليل**: الأخطاء والضعف والرسوم.

وتبقى كل وظائف v8 مثل الاتجاه المستقل، الاستكمال الذكي، سجل الأخطاء، التكرار، الخطط، والمراجعة المتباعدة متاحة.

## النص القرآني والصوت — Quran Focus

زر **النص** بجوار الحفظ الجديد أصبح وضع تركيز للحفظ:

- النص العثماني QPC Hafs.
- تبويب **صفحة المصحف** لنفس موضع الحفظ عند تثبيت مصحف المدينة PDF.
- الشيخ محمود خليل الحصري والشيخ مشاري راشد العفاسي فقط.
- سرعات `0.75× / 1× / 1.25×`.
- تكرار الآية 1 / 3 / 5 مرات.
- وضع تلقين بفاصل 3 / 5 / 8 ثوانٍ.
- إعادة النطاق كاملًا.
- Mini Player يستمر بعد إغلاق نافذة النص.

## مصحف المدينة النبوية الأصلي

أضيفت صفحة مستقلة باسم **المصحف**.

المبدأ في v9: لا نعيد إنشاء صفحة المصحف بخط عثماني؛ بل نوجّه المستخدم إلى **المصدر الرسمي لمجمع الملك فهد** ثم نتيح تثبيت ملف PDF على الجهاز.

بعد تثبيت PDF داخل التطبيق:

- يعمل المصحف Offline.
- قارئ من الصفحة 1 إلى 604.
- حفظ آخر صفحة.
- علامات مرجعية محلية.
- صفحة واحدة أو صفحتان متقابلتان على الشاشات الكبيرة.
- Fullscreen.
- فتح الصفحة الموافقة تلقائيًا من نافذة «النص» بحسب السورة والآية.
- حذف المصحف لا يمس بيانات الطلاب.
- زر مستقل لتنزيل نص المصحف للعمل دون إنترنت.

يوجد أيضًا زر لأصل الطباعة المتجهي AI 1441 المستضاف على نطاق مجمع الملك فهد. تفاصيل المصادر في `MUSHAF-SOURCES.md`.

> ملاحظة تقنية: المتصفح لا يملك صلاحية تثبيت ملف تم تنزيله من تبويب خارجي تلقائيًا. لذلك مسار PDF الآمن هو: **تحميل من المصدر الرسمي → الرجوع للتطبيق → تثبيت ملف PDF**. بعد ذلك القراءة Offline بالكامل من IndexedDB.

## الإنتاجية

- `Ctrl/⌘ + K` أو `/`: البحث السريع.
- `N`: فتح حصة جديدة عندما لا يكون المؤشر داخل حقل إدخال.
- `Ctrl/⌘ + Z`: تراجع عن الأرشفة الحديثة المدعومة.
- كليك يمين على الطالب في Windows لفتح قائمة الإجراءات.
- زر **حضر الجميع** لتسجيل الحلقة بسرعة ثم تعديل الغائبين فقط.
- شاشة مجموعات سريعة مع رسالة جماعية للمجموعة.

## الخصوصية والتخزين

التطبيق Local‑First:

- IndexedDB هو المخزن الأساسي.
- Backup JSON متاح.
- آخر 5 نسخ تلقائية محلية من طبقة v8 ما زالت تعمل.
- PIN وWebAuthn / Windows Hello ما زالا متاحين.
- المزامنة المشفرة الاختيارية عبر Supabase ما زالت متاحة.
- ملف المصحف والملاحظات الصوتية يظلان على الجهاز.
