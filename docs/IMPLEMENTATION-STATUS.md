# حالة تنفيذ v10.1 Clean PWA

## المتطلبات المعتمدة والمنفذة

- [x] إزالة طبقات v8/v9 من Runtime النهائي وبناء PWA نظيفة Modular.
- [x] الصفحة الرئيسية مبسطة: أرقام اليوم + بدء حصة + طلاب اليوم + اختصارات أساسية فقط.
- [x] أربع لوحات ألوان قابلة للاختيار، مع Emerald & Ivory كافتراضي.
- [x] أيقونة التطبيق 96/192/512 + Maskable + Apple Touch + Standalone Manifest.
- [x] حفظ الحصة وإرسال واتساب في نهاية الحصة فقط، بدون شريط عائم.
- [x] سجل أخطاء التسميع Accordion مغلق افتراضيًا.
- [x] اقتراح المراجعة Accordion مغلق افتراضيًا.
- [x] زر «نفس التكليف» عند درجة ضعيف للحفظ الجديد والمراجعة القريبة والبعيدة.
- [x] مراجعة الأجزاء على مستوى السور: تم / يعاد / لم يسمع، مع ترحيل المتبقي فقط.
- [x] مراجعة مجموعة السور بنفس منطق تم / يعاد / لم يسمع.
- [x] فصل مراجعة الأجزاء عن مراجعة السور وتشغيل/إيقاف كل واحد مستقلًا.
- [x] اتجاه مستقل للحفظ والقريب والبعيد والأجزاء والسور.
- [x] أسماء الأجزاء بالأسماء المعروفة بدل الأرقام فقط.
- [x] زر «النص» أثناء التسميع وفي التكليف القادم، ومراجعة السور.
- [x] قارئ نص قرآني مع الحصري ومشاري والتكرار والتلقين والسرعة.
- [x] مصحف المدينة PDF كامل: تنزيل داخلي، نسبة تقدم، إيقاف مؤقت، متابعة، إلغاء، ورابط/استيراد كـ fallback.
- [x] قارئ المصحف Offline بعد التثبيت مع صفحة واحدة أو صفحتين وآخر صفحة.
- [x] قسم الحديث والدعاء.
- [x] تحميل وانتقاء 200 حديث قصير من صحيح البخاري مع الراوي/التخريج/الدرجة وفلترة موضوعية.
- [x] تحميل 60 دعاء وذكر من بيانات حصن المسلم مع المصدر والتصنيف.
- [x] ربط الحديث أو الدعاء بالطالب كمهمة أو تكليف أسبوعي.
- [x] في الحصة التالية: «حفظه» أو «يعاد» للحديث والدعاء السابق، مع إعادة تلقائية عند اختيار يعاد.
- [x] رسالة واتساب مختصرة أو تفصيلية وهوية الأكاديمية و«بالقرآن نحيا» ورابط Facebook من الإعدادات.
- [x] Timeline للطالب و«أين توقفنا؟» وخريطة تقدم بلا نسب مئوية.
- [x] تقرير شهري قابل للطباعة/الحفظ PDF عبر نافذة الطباعة.
- [x] الملاحظات الصوتية المحلية داخل الحصة.
- [x] PIN وWebAuthn/Windows Hello عند دعم الجهاز.
- [x] آخر خمس نسخ احتياطية تلقائية + نسخ يدوية + استيراد/تصدير JSON.
- [x] Data Health Check.
- [x] Demo mode وOnboarding.
- [x] الحلقات والحضور الجماعي ورسالة جماعية.
- [x] المهام، البحث السريع Ctrl+K، واختصارات لوحة المفاتيح الأساسية على Windows.
- [x] الطلاب النشطون/المتوقفون/المؤرشفون والمفضلة.
- [x] تصميم Responsive للهاتف وWindows وTouch targets مناسبة.

## ملاحظات اختبار قبل النشر النهائي

- [ ] اختبار Runtime فعلي بعد الرفع على GitHub Pages على Android وWindows كما طلب المستخدم.
- [ ] اختبار رابط PDF من بيئة GitHub Pages لأن نجاح التنزيل الداخلي يعتمد على CORS/Range لدى المصدر؛ عند المنع يعمل مسار الرابط الخارجي + الاستيراد.
- [ ] مراجعة شرعية بشرية نهائية لقائمة الـ200 حديث المنتقاة آليًا قبل اعتمادها للطباعة أو النشر العام، رغم أن المصدر المقيد هو صحيح البخاري.
- [ ] مراجعة اختيار الـ60 دعاء من حيث مناسبة طولها للأطفال؛ المصدر يبقى حصن المسلم.
