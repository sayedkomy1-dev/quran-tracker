# مصادر خارجية معتمدة/مقترحة

## المصحف

- مجمع الملك فهد لطباعة المصحف الشريف: المرجع لهوية مصحف المدينة وكون النسخة المشهورة 604 صفحات.
- PDF mirror المستخدم افتراضيًا للتنزيل البرمجي: `pdf.quran.ws`، وليس موقعًا رسميًا للمجمع. لذلك يظل رابط المصدر قابلًا للتغيير من الإعدادات.

## الحديث والأدعية

قاعدة المحتوى النهائية لم تُدمج بعد. المرشح التقني: Open Hadith Data (بيانات منظمة، الراوي/المرجع/الدرجة، وHisn al-Muslim). يجب إجراء مراجعة بشرية/مصدرية قبل اعتماد قائمة الأطفال النهائية.
