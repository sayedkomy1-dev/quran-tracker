# خطة مراجعة الإصدار 11.12.1-beta.25 — أكاديمية الإمام

**الحالة: للمراجعة المحلية فقط، غير منشور**. الأساس: 11.12.1-beta.24 (النسخة التي أكد المستخدم وصولها إلى الهاتف). ملفات الإصدارات 2 و4 و5 و6 و12 والنسختان المصدريتان المرفقتان استُخدمت للمقارنة المرجعية فقط ولم تُنسخ فوق الأساس.

## نطاق التغيير المقصود

1. تبويب **الملاحظات**: أربعة أزرار كبيرة متتابعة: «مشاركة صوت التكليف (الحفظ الجديد)» ثم «حفظ الحصة» ثم «حفظ وإرسال لولي الأمر» ثم «مشاركة أخطاء الحصة». الأزرار الأصلية لا تُنسخ، ولا يوجد شريط حفظ عائم جديد. يظل تغيير قارئ الصوت اختيارًا منفصلًا اختياريًا.
2. **سجل أخطاء واحد** داخل الملاحظات فقط في الوضعين المبسط والسريع؛ تسجيل الأخطاء أثناء التسميع/التصحيح عبر الوظائف القائمة، بدون تغيير مخطط البيانات.
3. **نوع الخطأ اليدوي** يُخزن مع سياقه إن اختاره المحفظ: تسميع، حفظ جديد، مراجعة قريبة/بعيدة، مراجعة سور/أجزاء/أرباع/أحزاب، وتصحيح النص الجديد. لا نخمن سياق أخطاء تاريخية لم تحفظ هذا الحقل.
4. **مشاركة الأخطاء**: عرض تقرير مستقل يشمل التصحيحات اليدوية وعلامات الآيات والكلمات والحروف. طرق الإخراج: تنزيل ومشاركة HTML، طباعة/حفظ PDF من المتصفح، مشاركة صور PNG، نسخ النص. يظل التقرير الكامل القديم متاحًا ضمن خيارات رسالة ولي الأمر.
5. رسائل واتساب عبر **حفظ وإرسال** تبقى بالآلية الأصلية، مع تفاصيل الأخطاء المسجلة نصيًا. الملفات لا تُرفق تلقائيًا برسالة `wa.me`؛ مشاركة الملف تحتاج إجراء مشاركة صريحًا عبر الهاتف أو إرفاقه يدويًا، حفاظًا على عدم ادعاء إرسال لم يقع.
6. تبويب **إدارة ولي الأمر** في «المزيد»: تعليمات وخطوات وترتيب أوضح وأدوات الأمان الثانوية مطوية افتراضيًا. لم يتم تعديل استدعاءات الخادم، أو PIN، أو الربط، أو أي SQL.
