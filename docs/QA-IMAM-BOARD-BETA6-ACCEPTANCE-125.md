# سجل القبول الكامل — ١٢٥ معيارًا

الإصدار التجريبي السادس. هذا السجل يعيد البنود الأصلية **دون اعتبار فحص الوحدات موافقة نهائية**. جميع البنود التالية تتطلب إجراء قبول منفصلًا على نسخة اختبارية، أو تدوين دليل آلي مباشر واضح للوظيفة المقصودة. لا تُكتب «ناجح» إلا مع دليل ورقم إصدار وملاحظات ولقطة شاشة عند الحاجة.

- اختبارات الملفات البرمجية: ناجحة (انظر تقرير الإصدار)، ولا تعني نجاح كل بند من البنود أدناه.
- تجربة متصفح مع تكامل قاعدة البيانات الأصلية ونافذة العرض: لم تكتمل في هذه البيئة.
- الصوت عبر الاجتماعات والحصص الحقيقية والأدوار المختلفة: تنتظر الاختبار بالتعاون مع مالك المشروع.
- الفحوص الشرعية وحقوق النصوص المستوردة: لا تندرج ضمن نجاح اختبارات جافاسكريبت.
