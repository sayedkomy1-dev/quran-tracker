تطبيق التحديث — أكاديمية الإمام

هذه الحزمة تنظف نسخًا تاريخية مكررة فقط. لا تغيّر وظائف التطبيق أو بيانات الطلاب أو قاعدة البيانات.

الطريقة:
1) افتح ZIP.
2) حدّد كل المحتويات وانسخها.
3) الصقها داخل مجلد مشروع quran-tracker الحالي الذي يفتحه GitHub Desktop.
4) وافق على استبدال الملفات عند ظهور الرسالة.
5) بعد اكتمال النسخ، افتح مجلد المشروع وشغّل APPLY_CLEANUP.bat بالنقر المزدوج.
6) وافق على التنفيذ بكتابة/اختيار Y في نافذة الأداة.
7) افتح GitHub Desktop وراجع قائمة Changes. لا تعمل Commit قبل التأكد أن الملفات المحذوفة هي المذكورة في تقرير التنظيف.
8) اكتب Commit Message ثم Commit to main ثم Push origin.

مهم:
- لا تحذف مجلد .git ولا تستبدل مجلد المشروع كله.
- APPLY_CLEANUP.bat يعمل من داخل مجلد المشروع، ولا يحتاج PowerShell أو كتابة أوامر.
- الأداة تتحقق من SHA-256 قبل حذف كل ملف. أي ملف مختلف عن النسخة التي فُحصت سيُترك كما هو.
- ملفات CSS الأربعة محفوظة أصلًا في archive/historical-css.
- 54 ملفًا تاريخيًا محفوظة في OP-BETA12-HISTORICAL-SCREENSHOT-SOURCE-ARCHIVE.zip.
- الصور المرجعية العشرون تبقى كما هي.
- لا يوجد SQL جديد ولا تغيير في Local Schema 12.
- لا يوجد تغيير في ملفات التشغيل أو إصدار PWA؛ لذلك لا تتوقع إشعار تحديث داخل التطبيق من هذه الحزمة وحدها. التغيير هنا في تنظيم المستودع فقط.
