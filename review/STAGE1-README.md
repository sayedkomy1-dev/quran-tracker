# IMAM Beta28 RC14 — Repository Cleanup Stage 1

## النطاق
تنظيف تاريخي فقط، دون تغيير سلوك التطبيق أو رقم إصدار PWA.

- نقل 53 ملفًا من نسخة التطبيق التاريخية داخل `screenshots/` إلى أرشيف ZIP موثق.
- أرشفة سكربت PowerShell القديم الخاص بالتنظيف؛ طريقة التطبيق الحالية أصبحت بالنقر المزدوج على `APPLY_CLEANUP.bat`.
- إزالة أربعة ملفات CSS تاريخية من جذر التشغيل بعد حفظ نسخها المطابقة في `archive/historical-css/`.
- الاحتفاظ بالصور المرجعية العشرين داخل `screenshots/`.
- إضافة أداة Windows تتحقق من SHA-256 لكل ملف قبل حذفه؛ أي اختلاف يؤدي إلى إبقاء الملف.
- تحديث سجل الأرشفة ودليل التطبيق وبصمات المشروع.

## ما لم يتغير
- `VERSION` ونسخة `package.json` و`index.html` و`sw.js` لا تتغير. أُضيف اختبار تنظيف مستقل إلى أمر `npm test` فقط.
- Local Schema يبقى 12.
- لا SQL جديد.
- لا تغيير في Supabase أو المصادقة أو المزامنة.
- لا تغيير في مكتبة الصوت أو واتساب أو الحصص أو بوابات الطلاب وأولياء الأمور.
- لا حذف لأي بيانات أكاديمية.

## طريقة التطبيق
انسخ محتويات حزمة التحديث إلى جذر مستودع GitHub Desktop، ثم شغّل `APPLY_CLEANUP.bat` بالنقر المزدوج. لا تستخدم PowerShell. راجع كل التغييرات في GitHub Desktop قبل Commit وPush.

## ملاحظة الاختبار
اختبارات المشروع الآلية تُشغّل محليًا بواسطة `npm test`. تقرير نتائج هذا الإصدار موجود في `review/CLEANUP-STAGE1-REPORT.md`. نجاح الاختبارات الآلية لا يغني عن اختبار PWA على Android بعد النشر.
