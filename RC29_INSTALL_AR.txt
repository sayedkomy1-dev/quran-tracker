طريقة تركيب RC29

1) خذ نسخة احتياطية من مجلد مشروعك المحلي الحالي.
2) فك ضغط حزمة RC29 Updates Only.
3) افتح المجلد quran-tracker-main داخل الحزمة.
4) انسخ محتوياته إلى مجلد مشروعك المحلي الحالي، ووافق على الاستبدال.
5) لا توجد ملفات مطلوب حذفها في هذه الحزمة.
6) افتح GitHub Desktop، راجع التغييرات، ثم Commit وPush.
7) بعد اكتمال نشر GitHub Pages افتح التطبيق وهو متصل بالإنترنت. يجب أن يكتشف Service Worker الجديد ويعرض شريط التحديث. اضغط تحديث عندما يظهر.

شغّل ملف SQL الموحد مرة واحدة فقط من Supabase SQL Editor:
sql/RC29_Complete_Offline_Recitation_And_Assignment_Audio.sql

لا تستخدم PowerShell. لا ترفع حزمة المشروع الكامل فوق مشروعك إلا إذا أردت استبدال المجلد كاملًا؛ حزمة Updates Only هي الأنسب لطريقة عملك المعتادة.
